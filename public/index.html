Sobre o Sistema

Este sistema permite acompanhar partidas de futebol em tempo real. Os administradores podem registrar gols, cartões e controlar o andamento da partida, enquanto os espectadores acompanham as atualizações automaticamente.

Tecnologias utilizadas

  • ⚡ Node.js
  • 🚀 Express
  • 🔌 WebSocket para comunicação em tempo real
  • 🌐 HTML, CSS e JavaScript

Funcionalidades

  • ⚽ Criar partidas
  • 📊 Atualizar placar
  • ⚽ Registrar gols
  • 🟨 Registrar cartão amarelo
  • 🟥 Registrar cartão vermelho
  • 📡 Atualização em tempo real
  • 📜 Histórico de jogos
